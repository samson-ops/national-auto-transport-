NATIONAL AUTO TRANSPORT — WEBSITE PACKAGE
=========================================

CONTENTS
  index.html            The complete homepage (all CSS/JS is inside this one file)
  images/               All site images, named by where they're used

HOW TO USE
  1. Preview: double-click index.html to open it in any browser.
  2. Deploy: upload index.html and the images/ folder together to any
     web host (Netlify, Vercel, cPanel, GoDaddy, Hostinger, etc.).
     Keep the folder structure exactly as-is.

QUOTE FORM
  The form currently shows an on-page confirmation only. To receive
  leads, connect it to a form service (Formspree, Basin, Netlify Forms)
  or your CRM. The form has id="qform" and standard name attributes
  (from, to, vehicle, type, when, phone), so most services plug in
  by adding an action URL.
